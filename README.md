# Olympics SQL Analysis

## Project Overview
This project analyzes Olympic Games data using SQL Server to find insights about athletes, teams, and medals.

## Dataset
The project uses two tables:
- `athletes` — athlete details such as name, sex, height, weight, and team.
- `athlete_events` — Olympic participation, games, year, sport, event, and medal details.

## SQL Questions
1. Which team has won the maximum gold medals over the years?
2. Find the total silver medals won by each team and the year they won the maximum silver medals.
3. Find the player with the maximum gold medals among players who never won silver or bronze.
4. Find the player(s) with the maximum gold medals for each year.
5. Find the first year India won gold, silver, and bronze medals, along with the sport.
6. Find players who won gold medals in both Summer and Winter Olympics.
7. Find players who won gold, silver, and bronze medals in a single Olympic year.
8. Find players who won gold medals in the same event in three consecutive Summer Olympics, considering years from 2000 onward.

The goal is to practice SQL queries and analyze Olympic data to discover meaningful insights.
